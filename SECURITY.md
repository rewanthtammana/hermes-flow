# Security policy

## Supported versions

Only the latest release and the default branch receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Contact the repository maintainers privately using the security contact listed
by the published repository. Include a description, reproduction steps, and
impact, but do not include credentials, private session exports, or raw customer
data.

Hermes Flow is a local observer. It reads selected session metadata and writes
reports; it does not authenticate tool outcomes, enforce trusted paths, or
provide data-loss prevention. Review reports before sharing them.
